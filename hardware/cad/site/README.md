# alarmclock.audrow.com

The 3D viewer as a standalone static site, served by Cloudflare Workers.

- `public/index.html` is generated by `../clock.py` (the same page as `../viewer/index.html`, wrapped as a full HTML document). Don't edit it by hand; edit `../viewer_template.html` and re-run `python clock.py`.
- `wrangler.jsonc` deploys it as an assets-only Worker named `alarmclock-site`, on the custom domain `alarmclock.audrow.com`.

## Deploy

From this folder, on a machine logged in to the Cloudflare account that has the `audrow.com` zone:

```sh
npx wrangler login     # first time only
npx wrangler deploy
```

The first deploy creates the DNS record and TLS certificate for `alarmclock.audrow.com`; it can take a few minutes to start answering. To publish changes later, re-run `python ../clock.py`, then `npx wrangler deploy` again.

The page is public once deployed. It includes the cost estimates and parts list.
