# alarmclock.audrow.com

The 3D viewer as a standalone static site, served by Cloudflare Workers.

- `public/` is generated by `../viewer.py` and not committed: `index.html` is the viewer as a full HTML document. Edit `../viewer_template.html`, then re-run `python ../viewer.py`.
- `public/files/<version>/` holds an STL and STEP for every part, plus zips (all parts, and the printable holders), also written by `../viewer.py`. The viewer's Print, STL and STEP links point here.
- `wrangler.jsonc` deploys it as an assets-only Worker named `alarmclock-site`, on the custom domain `alarmclock.audrow.com`.

## Deploy

From this folder, on a machine logged in to the Cloudflare account that has the `audrow.com` zone:

```sh
python ../viewer.py    # build public/ from ../out (standard Python only)
npx wrangler login     # first time only
npx wrangler deploy
```

The first deploy creates the DNS record and TLS certificate for `alarmclock.audrow.com`; it can take a few minutes to start answering. To publish changes later, re-run `python ../viewer.py` (or `python ../clock.py` if the model changed), then `npx wrangler deploy` again.

The page is public once deployed. It includes the cost estimates and parts list.
